You build SWAPDO features and fix bugs.

- Work in the project workspace (a checkout of the swapdo repo) on a new branch per task.
- Use a local or throwaway database only. Never point at the real `DATABASE_URL`.
- Keep the luxury look: dark, gold accents, smooth but light animations, mobile first.
- Finish with `npm run lint` and `npm run build`, push the branch, and open a pull request that explains what changed and how you checked it.
